# v7 / 1.1 修复与升级

本次修改的是工作区源码，生成 APK；没有向真实板子或手机部署。

## 修复内容

- 补齐 `resetShell()`，恢复断线后的自动重连；连接中也可取消。
- 每次蓝牙连接独享 socket、发送队列、解析器和线程；旧任务不能关闭新连接。失败 socket 显式关闭，每种连接方式最多等待 15 秒。
- 终端使用 `escaped-v1` 双向转义协议。解析器处理拆包、粘包、重复开关终端；退出由控制帧确认，普通 `session ended` 文本不会切换模式。
- 终端启动及运行期间禁止发送管理 JSON，暂停定时查询；板端切换前丢弃旧行缓冲，在同一发送锁下切换模式。
- 实现独立关闭控制帧；PTY 非阻塞写入支持部分写入和 EAGAIN。
- 超长单条日志不会再卡住 `_shrink()`；增加帧长度、JSON 对象及参数类型检查。
- WiFi 修改串行执行，看门狗启动失败则不改配置。看门狗预算包含 apply、验证、回滚和清理；检查目标 SSID 和 wlan0 默认路由。回滚未验证成功时保留看门狗。
- 蓝牙关键注册失败退出，由 systemd 重启；拒绝连接时释放 FD。默认关闭配对，`bt-pair` 与守护共用 mgmt 锁。
- 手机端令牌迁移到 Android Keystore 加密存储；成功迁移才删除旧 localStorage 值，关闭 App 备份。

## 部署方式

当前源码已增加安装器与 systemd watchdog，就绪通知依赖新版 service 文件；不要仅替换 Python 网关。请使用项目根目录的 `sudo bash install.sh` 同步安装全部文件，或参考根目录 README 的离线升级方式。不要覆盖已有令牌、蓝牙配对记录和网络配置。

新 App 可使用旧网关的管理功能，但禁止启动旧协议终端。旧 App 请求新版网关终端时会得到协议参数错误；需要配套升级。

## 回归验证

当前工作区的无硬件检查：

```bash
python3 -m unittest discover -s tools -p 'test_*.py' -v
python3 tools/check_source.py
```

无硬件测试覆盖安装幂等性、配置与令牌保留、更新备份、watchdog 通知和响应裁剪。真实蓝牙收发与系统恢复需要另行验证。

板端部署后运行 `python3 tools/bt_term_test.py`，会通过本地 socket 连续开关两次真实 root PTY，并验证退出后仍能执行 `sys.info`。此测试不修改网络，但本次没有在板子执行。

真机还需验证：连续重连、连接中取消、终端大段粘贴、前台运行 top 时结束会话、WiFi 成功切换与错误密码回滚。模拟测试和 APK 编译不能替代这些硬件检查。
